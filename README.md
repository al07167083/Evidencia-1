# Sistema de Administración de Citas

Programa en Java para administrar citas de un consultorio médico. Proyecto final de la materia Computación en Java.

## Instalación y configuración

1. Tener instalado Java JDK 11
2. Clonar  el repositorio
3. Abrir el proyecto en IntelliJ IDEA
4. Ejecutar la clase Main.java

## Uso del programa

- Ingresar con usuario y contraseña
- Desde el menú se puede registrar doctores, pacientes y crear citas
